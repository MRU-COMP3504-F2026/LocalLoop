# User Manual

## High Level Description 

LocalLoop is a system designed to allow consumers to find and connect with local businesses. By taking the location of consumers and businesses alike, customers can freely explore and search for local businesses to support, In turn, businesses can better connect with local customers and with a platform to market their products and/or services. 

## Getting Started

Starting the system is simple. Some requirements need to be met to run our application:

Mobile Requirements:
- IOS 16.4 or Later
- Android 7.0 or Later

Browser Requirements:
- Google Chrome - Version 111+
- Microsoft Edge - Version 111+
- Mozilla Firefox - Version 111+
- Apple Safari - Version 16.4+


## How to run the application: 

The experience is the same whether you are a customer or a business owner. Go to the website and create an account. Make sure you allow your location to be shared with the app as well. Optional data tracking can be enabled if you want a more targeted advertisement experience if you are a customer. Once an account has been created, you will be able to explore local businesses in your area or run your business.

## User Guide

As of its current iteration, LocalLoop is a web platform which can facilitate the following features:
- Profile creation: the opening screen will prompt users to “join the loop” to create either a new business profile or shopper account. Upon choosing to create a business profile, users may provide information regarding their business’s name, email, target audience, images, a brief description, and location before publicizing the profile.
- Edit profile: the edit profile page allows users to edit details regarding their account with the exception of the account password. 
- Populate product/service listing: a tab which enables users to access their current listing and add a product or service. From here, users may add the product/service name, type, description, images, price, and quantity. 
- Preview account: upon accessing the tab, business users can preview the profile and how shoppers will see their profile from their inputted details to listings. 
- Edit account settings: allows users to edit (will need to ask/review page)

The following features are still in development/WIP as of writing:
